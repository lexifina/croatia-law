# Rješenje Ustavnog suda Republike Hrvatske broj: U-I-986/1999 od 4. srpnja 2001.

- Case: `U-I-986/1999`
- Decision: Rješenje o neprihvaćanju prijedloga za ocjenu akata zakonodavnog tijela - zakoni i akti - snage zakona
- Decision date: `2001-07-04`
- Conclusion (database): Ne prihvaća se prijedlog za pokretanje postupka za ocjenu suglasnosti s Ustavom Odluke o proglašenju Zakona o izborima zastupnika u Hrvatski državni sabor (“Narodne novine”, broj 116/99).
