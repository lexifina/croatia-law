# Obustava za zakone i druge akte zakonodavnog tijela Ustavnog suda Republike Hrvatske broj: U-I-919/2002 od 11. svibnja 2004.

- Case: `U-I-919/2002`
- Decision: Obustava za zakone i druge akte zakonodavnog tijela
- Decision date: `2004-05-11`
- Conclusion (database): Obustavlja se postupak za ocjenu suglasnosti s Ustavom odredaba članka 69.
