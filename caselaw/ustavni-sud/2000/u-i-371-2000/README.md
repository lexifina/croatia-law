# Rješenje Ustavnog suda Republike Hrvatske broj: U-I-371/2000 od 5. travnja 2000.

- Case: `U-I-371/2000`
- Decision: Rješenje o neprihvaćanju prijedloga za ocjenu akata zakonodavnog tijela - zakoni i akti - snage zakona
- Decision date: `2000-04-05`
- Conclusion (database): I. Ne prihvaća se prijedlog za pokretanje postupka za ocjenu suglasnosti s Ustavom Republike Hrvatske odredaba članka 2. stavaka 2., 3. i 4. Zakona o prestanku rada sudova udruženog rada ("Narodne novine", broj 53/90). II. Odbacuje se prijedlog za pokretanje postupka za ocjenu suglasnosti odredaba članka 2. stavaka 2., 3. i 4. Zakona o prestanku rada sudova udruženog rada s odredbom članka 382. stavka 4. točke 2. Zakona o parničnom postupku ("Narodne novine", br. 53/91, 91/92 i 112/99).
