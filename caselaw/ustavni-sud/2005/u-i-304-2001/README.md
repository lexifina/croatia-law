# Odbačaj za prijedlog za ocjenu akata zakonodavnog tijela Ustavnog suda Republike Hrvatske broj: U-I-304/2001 od 21. prosinca 2005.

- Case: `U-I-304/2001`
- Decision: Odbačaj za prijedlog za ocjenu akata zakonodavnog tijela
- Decision date: `2005-12-21`
- Conclusion (database): Odbacuje se prijedlog za pokretanje postupka za ocjenu suglasnosti s Ustavom članka 18. stavaka 2. i 3., članka 26a. stavka 2. i članka 28. Zakona o komunalnom gospodarstvu ("Narodne novine", broj 36/95., 70/97. i 128/99.). Zakona o izmjenama i dopunama Zakona o komunalnom gospodarstvu ("Narodne novine", broj 128/99.).
