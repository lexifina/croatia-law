# Rješenje Ustavnog suda Republike Hrvatske broj: U-II-2169/2008 od 9. srpnja 2008.

- Case: `U-II-2169/2008`
- Decision: Rješenje o neprihvaćanju prijedloga za ocjenu akata ostalih donosilaca (ministarstva-javna poduzeća-i r sve signatura II)
- Decision date: `2008-07-09`
- Conclusion (database): Ne prihvaća se prijedlog za pokretanje postupka za ocjenu suglasnosti s Ustavom i zakonom članka 2.
