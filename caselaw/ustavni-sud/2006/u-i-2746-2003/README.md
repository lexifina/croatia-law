# Rješenje Ustavnog suda Republike Hrvatske broj: U-I-2746/2003 od 8. ožujka 2006.

- Case: `U-I-2746/2003`
- Decision: Rješenje o neprihvaćanju prijedloga za ocjenu akata zakonodavnog tijela - zakoni i akti - snage zakona
- Decision date: `2006-03-08`
- Conclusion (database): I. Ne prihvaća se prijedlog za pokretanje postupka za ocjenu suglasnosti s Ustavom članka 203. točke 4. Zakona o zdravstvenoj zaštiti ("Narodne novine" broj 121/03., 44/05.-odluka Ustavnog suda Republike Hrvatske i 48/05.-ispravak). II. Odbacuje se prijedlog za ocjenu suglasnosti s Ustavom Ispravka Zakona o zdravstvenoj zaštiti ("Narodne novine" broj 48/05.).
