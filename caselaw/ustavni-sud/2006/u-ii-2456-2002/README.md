# Rješenje Ustavnog suda Republike Hrvatske broj: U-II-2456/2002 od 22. ožujka 2006.

- Case: `U-II-2456/2002`
- Decision: Rješenje o neprihvaćanju prijedloga za ocjenu akata ostalih donosilaca (ministarstva-javna poduzeća-i r sve signatura II)

- Conclusion (database): Ne prihvaćaju se prijedlozi za pokretanje postupka za ocjenu suglasnosti sa zakonom i Ustavom članaka 17., 29. i 30.
