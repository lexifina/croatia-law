# Odluka Ustavnog suda Republike Hrvatske broj: U-I-988/1998 od 17. ožujka 2010.

- Case: `U-I-988/1998`
- Decision: Odluka o ukidanju zakona i drugih akata zakonodavnog tijela
- Decision date: `2010-03-17`
- Conclusion (database): Na temelju članka 38. stavka 2.
