# Članak 28.
1) Zaposlenik ili njegova obitelj ima pravo na pomoć u slučaju.
- smrti zaposlenika koji izgubi | 3 prosječne mjesečne plaće život u obavljanju ili povodu | i troškove pogreba; obavljanja službe odnosno rada - smrti zaposlenika |  |  | 3 prosječne mjesečne plaće; - smrti supružnika, djeteta i |  | 1 prosječna mjesečna plaća roditelja u skrbi |  |  | isplaćena po zaposleniku u |  |  |  |  | Republici Hrvatskoj u |  |  |  |  | prethodna tri mjeseca
2) Zaposlenik ili njegova obitelj imaju pravo na pomoć u slučaju:
- nastanka teške invalidnosti |  | 2 najniže bruto plaće u javnim djece i supružnika zaposlenika | službama; - nabave medicinskih pomagala |  | 2 najniže bruto plaće u javnim i participacije pri kupnji |  | službama; prijeko potrebnih lijekova u inozemstvu
3) Ako su prema propisima o izvršenju državnog proračuna osigurana sredstva, zaposlenik ili njegova obitelj ima pravo na pomoć u slučaju:
- nastanka teške invalidnosti |  | 2 prosječne mjesečne plaće; zaposlenika - bolovanja dužeg od 90 dana |  | 1 prosječna mjesečna plaća; - potpore djece zaposlenika |  | 2 prosječne mjesečne plaće; stradalog ili poginulog u domovinskom ratu - otklanjanja posljedica |  | 2 prosječne mjesečne plaće elementarne nepogode |  |  | isplaćene po zaposleniku u |  |  |  |  | Republici Hrvatskoj u |  |  |  |  | prethodna tri mjeseca
