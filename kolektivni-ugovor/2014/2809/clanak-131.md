# Članak 131.
Za ostale poslodavce, doktore medicine/dr. med. dent., koji obavljaju djelatnost sekundarne - specijalističko-konzilijarne zdravstvene zaštite i koji ostvaruje prihod sustavom cijena x usluga, glede obračuna plaće radnika primjenjuju se ista mjerila kako je propisano člankom 103. i 104.
