# Članak 4.
U članku 42. iza stavka 3. dodaje se novi stavak 4. koji glasi:
»(4) Zakonom se može za određene prekršaje propisati obvezna primjena zaštitne mjere zabrane upravljanja motornim vozilom.«
Dosadašnji stavak 4. koji postaje stavak 5. mijenja se i glasi:
»(5) Primjena negativnih bodova za počinjene prekršaje protiv sigurnosti prometa može dovesti i do oduzimanja vozačke dozvole koja se smatra zaštitnom mjerom prestanka važenja vozačke dozvole.«
