# Članak 2.
Vodeći broj sastoji se od sedam numeričkih znakova od kojih:
- prvi znak (n() predstavlja skupinu depozitne institucije;
- slijedeća tri znaka (n(n(n() predstavljaju jedinstveni kod depozitne institucije ;
- slijedeća dva znaka (n(n() služe za interne potrebe depozitne institucije u svrhu šifriranja poslovnih jedinica, pri čemu znakovi "00" označavaju samu depozitnu instituciju;
- posljednji znak (n() predstavlja kontrolni broj izračunat po međunarodnoj nocmi ISO 1064 "Modul 11,10".
