# Članak 2.
1. Stranke koje sudjeluju u postupku pred ŠAS snose troškove postupka.
2. Troškovi postupka sastoje se od:
a) upisne takse;
b) troškova nagrada arbitara i posrednika;
c) administrativnih troškova;
d) materijalnih troškova postupka.
3. Prilikom podnošenja tužbe odnosno protutužbe tužitelj je dužan radi podmirenja troškova postupka iz točaka a) do c) ovoga članka uplatiti u korist ŠAS iznos utvrđen tarifom koja je sastavni dio ove odluke.
4. Odredba stavka 2. ovoga članka ne primjenjuje se ako je predsjednik ŠAS odobrio odgodu plaćanja u smislu čl. 51. st. 4. Arbitražnih pravila ŠAS.
