# Članak 3.

Dosadašnje točke 2. do 4. postaju točke 1. do 3.
Iza točke 3. dodaje se nova točka 4. koja glasi:
»4. ako onemogući isključenje mjernog mjesta zbog neplaćanja potrošene električne energije«.
