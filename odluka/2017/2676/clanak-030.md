# Članak 30.
U tablici u poglavlju 3.2.5. Upute kontrola 416 mijenja se i glasi:
Ako je Portfelj = »TRG«, »FOB«, »FOS«, »FOP«, »ATR« ili »DIP« i ako je Instrument = »A*«, tada je Značajka kapitala = »N« ili »A«. | 416
Kontrola 418 mijenja se i glasi:
Ako je Portfelj = »ATR« i ako je Instrument = »P*«, tada je Značajka kapitala <> »A«. | 418
Kontrola 424 mijenja se i glasi:
Ako je Značajka kapitala = »H«, »P« ili »D«, tada je Portfelj = »ATR« i Instrument počinje s P. | 424
Kontrola 432 mijenja se i glasi:
Ako je Instrument = »P0601«, tada je Portfelj = »TRG« ili »GOP«. | 432
Kontrola 448 mijenja se i glasi:
Ako je Vrsta iznosa = 7, 20, 63, 64 ili 65, tada je Iznos >= 0. | 448
