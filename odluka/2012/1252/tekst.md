I.
Usvajaju se jamstveni programi Hrvatske agencije za malo gospodarstvo, i to:
- Jamstveni program »Novi poduzetnici«
- Jamstveni program »Poljoprivrednici«
- Jamstveni program »Likvidnost«
- Jamstveni program »Rast«
- Jamstveni program »Financijski leasing«
- Jamstveni program »Inovacije«
- Jamstveni program »Činidbena jamstva«.
Jamstveni programi iz stavka 1. ove točke sastavni su dio ove Odluke.
II.
Usvajaju se Opći uvjeti za izdavanje jamstava Hrvatske agencije za malo gospodarstvo.
Opći uvjeti iz stavka 1. ove točke sastavni su dio ove Odluke.
III.
Obvezuje se Hrvatska agencija za malo gospodarstvo da, u roku 30 dana od dana donošenja ove Odluke, pripremi sve potrebne akte za provedbu programa i Općih uvjeta iz točaka I. i II. ove Odluke.
IV.
Danom donošenja provedbenih akata od strane Hrvatske agencije za malo gospodarstvo, ukidaju se svi raniji jamstveni programi Hrvatske agencije za malo gospodarstvo, i to:
- »Jamstveni program Područja posebnog državnog interesa« (»Narodne novine«, br. 182/2004, 86/2005, 87/2005, 105/2007 i 56/2009)
- »Jamstveni program Poljoprivreda« (»Narodne novine«, br. 182/2004, 75/2006, 105/2007, 119/2008, 122/2008 - ispravak, 56/2009 i 129/2011)
- »Jamstveni program Novi poduzetnik« (»Narodne novine«, br. 182/2004, 86/2005, 87/2005, 105/2007 i 56/2009)
- »Jamstvenog program Obrtni kapital« (»Narodne novine«, br. 182/2004, 86/2005, 87/2005, 105/2007 i 56/2009)
- »Jamstveni program Rast i razvoj« (»Narodne novine«, br. 182/2004, 86/2005, 87/2005, 105/2007 i 56/2009)
- »Jamstveni program Poduzetnik u zoni« (»Narodne novine«, br. 105/2007 i 56/2009)
- »Jamstveni program Nove tehnologije« (»Narodne novine«, br. 105/2007 i 56/2009)
- »Jamstveni program Mikrokrediti« (»Narodne novine«, broj 56/2009)
- »Jamstveni program Financiranje pronalazaka« (»Narodne novine«, broj 56/2009)
- »Jamstveni program Žene poduzetnice« (»Narodne novine«, broj 33/2011).
V.
Zahtjevi za jamstva primljeni do dana donošenja provedbenih akata, obradit će se po uvjetima iz programa koji su bili na snazi na dan njihova primanja.
VI.
Ova Odluka stupa na snagu danom donošenja, a objavit će se u »Narodnim novinama«.
