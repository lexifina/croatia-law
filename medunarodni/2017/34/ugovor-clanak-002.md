# Članak 2.
Članak 2. Ugovora mijenja se tako da se iza stavka 2. dodaju novi stavci 3. i 4. koji glase:
»3. Nijedna ugovorna stranka neće na svom teritoriju neopravdanim ili diskriminirajućim mjerama onemogućavati upravljanje, održavanje, korištenje, uživanje, stjecanje ili raspolaganje ulaganjima ulagatelja druge ugovorne stranke.
4. Svaka ugovorna stranka će cijelo vrijeme na svom teritoriju ulaganjima i povratima ulagatelja druge ugovorne stranke pružati pošten i pravičan tretman i punu zaštitu i sigurnost.«
