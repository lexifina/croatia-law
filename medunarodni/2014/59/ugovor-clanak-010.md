# Članak 10.
Proračun
Proračun DPPI SEE sastoji se od godišnjih doprinosa stranaka DPPI SEE.
Tajništvo DPPI SEE izrađuje, na temelju godišnjeg plana rada DPPI SEE, proračun koji će se dati na odobrenje na regionalnom sastanku DPPI SEE tijekom jesenskog zasjedanja. Tajništvo DPPI SEE također izrađuje dodatne planove rada i proračune za projekte koji se mogu provesti uz pomoć partnera DPPI SEE.
Partneri DPPI SEE koji doprinose proračunu projekata DPPI SEE mogu zatražiti posebna izvješća o reviziji.
