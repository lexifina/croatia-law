# Članak 15.
1. Ovaj Protokol otvoren je za potpisivanje svakoj državi koja je potpisala ili ratificirala Konvenciju ili joj je pristupila.
2. Ovaj Protokol podliježe ratifikaciji od strane svake države koja je ratificirala Konvenciju ili joj je pristupila. Isprave o ratifikaciji polažu se kod glavnog tajnika Ujedinjenih naroda.
3. Ovaj je Protokol otvoren pristupanju svake države koja je ratificirala Konvenciju ili joj je pristupila.
4. Pristupanje se vrši polaganjem isprave o pristupanju kod glavnog tajnika Ujedinjenih naroda.
