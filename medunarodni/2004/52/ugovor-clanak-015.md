# Članak 15.
ODOBRAVANJE REDOVA LETENJA
1. Određeni zračni prijevoznici jedne ugovorne stranke obavijestit će zrakoplovne vlasti druge ugovorne stranke o svojim prometnim programima najmanje trideset (30) dana prije početka obavljanja zračnog prometa. Program će posebno obuhvatiti redove letenja, učestalost letenja i tipove zrakoplova koji će se koristiti.
2. O bilo kakvoj izmjeni u programu zračnog prometa do koje je došlo kasnije isto će se tako poslati obavijesti.
