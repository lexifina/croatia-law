# Članak 25.
Državni službenici primaju se u državnu službu uz obvezni probni rok
od tri mjeseca.
Za državnog službenika koji u probnom roku nije zadovoljio, po proteku
probnog roka ministar ili drugi čelnik tijela državne vlasti, odnosno tijelo
koje je imenovalo državnog službenika donosi rješenje o otpustu iz državne
službe. Protiv rješenja o otpustu iz državne službe protekom probnog roka
mogu se ulagati pravna sredstva.
