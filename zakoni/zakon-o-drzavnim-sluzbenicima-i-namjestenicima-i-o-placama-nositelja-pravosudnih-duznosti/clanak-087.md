# Članak 87.
Državni stručni ispit sastoji se od općeg i posebnog dijela. Opći dio
zajednički je za sve vježbenike bez obzira na zanimanje, a posebni dio
ispita sastoji se od provjere posebnih znanja potrebnih za obavljanje pojedine
državne službe.
Program općeg dijela stručnog ispita propisuje ministar nadležan za
poslove opće uprave, a program posebnog dijela stručnog ispita propisuje
ministar ili drugi čelnik tijela državne uprave nadležan za pojedino upravno
podrućje.
