# Članak 6.
Subjekti iz članka 2. ovoga Zakona razvrstavaju se u područja, potpodručja,
odjeljke, skupine, razrede i podrazrede Nacionalne klasifikacije prema
djelatnostima što ih obavljaju. Ako subjekt iz članka 2. ovoga Zakona obavlja
više djelatnosti, razvrstava se prema djelatnosti kojom se pretežito bavi.
