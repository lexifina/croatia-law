# Članak 59.
Ugovornom diplomatu služba prestaje protekom ugovorenog roka, a prije
proteka tog roka:
1. opozivom od predsjednika Republike,
2. ako mu je pravomoćnom odlukom zbog povrede službene dužnosti izrečena
mjera udaljenja iz službe vanjskih poslova,
3. rješenjem ministra vanjskih poslova,
4. ako je jedanput ocijenjen ocjenom "ne zadovoljava",
5. sporazumom.
4. Mirovanje radnog odnosa
