# Članak 190.
(1) Lučka uprava, na godišnjoj razini, uz suglasnost Ministarstva, donosi sljedeće planske dokumente:
a) Godišnji program rada s financijskim planom
b) Operativni program građenja i modernizacije lučkih građevina
c) Operativni program održavanja lučkih građevina.
(2) Upravitelj luke za posebne namjene dužan je izraditi i dostaviti Ministarstvu plan razvitka luke za razdoblje za koje se izrađuje plan iz članka 133. ovoga Zakona.
