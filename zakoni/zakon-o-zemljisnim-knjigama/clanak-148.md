# Članak 148.
(1) Žalba protiv rješenja će se zabilježiti, a zabilježba će se izbrisati po službenoj dužnosti kada postupak bude pravomoćno okončan.
(2) Revizija protiv rješenja će se zabilježiti, a zabilježba će se izbrisati po službenoj dužnosti kada se donese odluka povodom revizije.
(3) Protiv rješenja o zabilježbi žalbe i revizije posebna žalba nije dopuštena.
