# Članak 4.
U članku 13. stavku 2. iza točke 3. dodaje se nova točka 4. koja glasi:
»4. donosi opći akt o ustroju radnih mjesta sveučilišta«.
Dosadašnje točke 4. do 8. postaju točke 5. do 9.
Iza stavka 3. dodaje se novi stavak 4. koji glasi:
»(4) Rektor javnog sveučilišta dužan je ishoditi prethodnu suglasnost Ministarstva na dio općeg akta kojim se uređuje ustroj radnih mjesta izvan članka 4. stavka 3. točke 1. ovoga Zakona.«.
Dosadašnji stavak 4. postaje stavak 5.
