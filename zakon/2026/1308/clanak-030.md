# Članak 30.
U članku 59. iza stavka 3. dodaje se novi stavak 4. koji glasi:
»(4) Sveučilišni odnosno stručni diplomski studij može upisati i osoba koja je već završila odgovarajući diplomski studij ili sveučilišni integrirani studij prema uvjetima koje utvrđuje visoko učilište u skladu s odredbama stavka 3. ovoga članka.«.
Dosadašnji stavak 4. postaje stavak 5.
