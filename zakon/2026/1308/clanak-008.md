# Članak 8.
U članku 20. stavku 2. iza točke 3. dodaje se nova točka 4. koja glasi:
»4. donosi opći akt o ustroju radnih mjesta fakulteta odnosno umjetničke akademije«.
Dosadašnje točke 4. do 8. postaju točke 5. do 9.
Iza stavka 3. dodaje se novi stavak 4. koji glasi:
»(4) Dekan na javnom visokom učilištu dužan je ishoditi prethodnu suglasnost Ministarstva na dio općeg akta kojim se uređuje ustroj radnih mjesta izvan članka 4. stavka 3. točke 1. ovoga Zakona.«.
Dosadašnji stavak 4. postaje stavak 5.
