# Članak 101.
U članku 192. iza stavka 2. dodaje se novi stavak 3. koji glasi:
»Nakon što se tuženik upustio u raspravljanje o glavnoj stvari, umjesto tužitelja može u parnicu stupiti novi tužitelj samo ako tuženik na to pristane.«
U dosadašnjem stavku 3. koji postaje stavak 4. riječ: »tuženika« zamjenjuje se riječju: »stranke«.
