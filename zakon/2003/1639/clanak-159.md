# Članak 159.
U članku 301. stavku 1. iza riječi: »presuđena,« dodaje se riječ: »ili«, a riječi: »ili da se tužitelj pred sudom odrekao tužbenog zahtjeva,« brišu se.
Stavak 2. briše se.
U dosadašnjem stavku 3. koji postaje stavak 2. riječi: »vijeće odlučilo« zamjenjuju se riječima: »sud odlučio«.
U dosadašnjem stavku 4. koji postaje stavak 3. brojka: »3.« zamjenjuje se brojkom: »2.«, a riječi: »da li se tužitelj pred sudom odrekao tužbenog zahtjeva« brišu se.
