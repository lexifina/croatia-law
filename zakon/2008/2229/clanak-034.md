# Članak 34.
U članku 33.a u uvodnoj rečenici stavka 1. riječ: »Zavod« zamjenjuje se riječju: »Ministarstvo«, riječ: »stjecanju« zamjenjuje se riječju: »dodjeljivanje«, a iza riječi: »ako« dodaju se riječi: »je utvrđeno da:«.
U točki 2. podstavku 2. riječ: »stjecanja« zamjenjuje se riječju: »dodjeljivanja«.
U stavku 2. riječi: »iza stavka 2.« zamjenjuju se riječima: »iz stavka 1.«.
