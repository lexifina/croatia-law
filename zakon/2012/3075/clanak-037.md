# Članak 37.
U članku 79. stavku 2. riječi: »Općinski načelnik, gradonačelnik i župan dužni su« zamjenjuju se riječima: »Predsjednik predstavničkog tijela dužan je«.
Iza stavka 2. dodaje se stavak 3. koji glasi:
»Predsjednik predstavničkog tijela dužan je akte iz stavka 2. ovoga članka bez odgode dostaviti općinskom načelniku, gradonačelniku, odnosno županu.«.
