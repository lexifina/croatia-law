# Članak 5.
Članak 6. mijenja se i glasi:
"(1.) Garancije iz članka 4. stavka 3. podstavka 1. ovoga Zakona, Agencija daje bankama i drugim pravnim osobama-kreditorima.
(2.) Sredstva potpore iz članka 4. stavka 3. podstavka 2. ovoga Zakona, Agencija isplaćuje na način utvrđen odlukama Nadzornog odbora, a u skladu s programima iz članka 4. stavka 4. ovoga Zakona."
