# Članak 50.
Iza članka 108. dodaje se članak 108a. koji glasi:
Članak 108a.
Rektor može biti razrješen dužnosti prije isteka roka iz stavka 2. članka 108. ovoga Zakona:
- ako ne ispunjava dužnosti rektora,
- ako prekrši zakonske ili podzakonske propise ili odredbe statuta ili općih akata sveučilišta,
- ako zlouporabi položaj rektora,
- ako svojim ponašanjem povrijedi ugled dužnosti koju obnaša,
- ako izgubi sposobnost obavljanja dužnosti.
Odluku o pokretanju postupka razrješenja donosi sveučilišni senat.
O razrješenju odlučuje sveučilišni senat tajnim glasovanjem.
