# Članak 3.
U članku 6. dodaje se novi stavak 2. koji glasi:
"(2) Najkraći porezno dopustivi rokovi korištenja pojedine dugotrajne imovine, način otpisa kao i mogućnost ubrzanog otpisa uređuju se Pravilnikom o amortizaciji kojeg donosi ministar financija."
Dosadašnji stavci 2., 3. i 4. postaju stavci 3., 4. i 5.
