# Članak 17.
U članku 50. stavku 2. riječi: "prema odluci Zavoda" zamjenjuju se riječima: "na temelju pravilnika koji donosi ministar".
U stavku 4. riječi: "prema odluci Zavoda" zamjenjuju se riječima: "na temelju pravilnika koji donosi ministar", a riječi: "Zavod donio odluku" zamjenjuju se riječima: "ministar donio pravilnik".
