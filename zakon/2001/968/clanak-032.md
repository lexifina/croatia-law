# Članak 32.
U članku 49. stavku 1. riječi: »u pravilu« brišu se, a riječi: »tri mjeseca« zamjenjuju se riječima: »šest mjeseci«.
Stavak 2. briše se.
U dosadašnjem stavku 3. koji postaje stavak 2. u prvoj rečenici riječi: »jedne godine« zamjenjuju se riječima: »šest mjeseci«. U drugoj rečenici riječi: »Ministarstvo pravosuđa« zamjenjuju se riječima: »Središnji ured Uprave za zatvorski sustav«.
U dosadašnjem stavku 4. koji postaje stavak 3. broj: »3.« zamjenjuje se brojem »2.«.
