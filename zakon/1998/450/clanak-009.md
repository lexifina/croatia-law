# Članak 9.
U članku 73. stavku 2. podstavku 3. iza riječi: "kao zamjenici državnog odvjetnika Republike Hrvatske" stavlja se točka, a zarez i riječi iza njega brišu se.
Iza stavka 2. dodaju se stavci 3. i 4. koji glase:
"Danom prestanka državnoodvjetničke dužnosti državnom odvjetniku, odnosno zamjeniku državnog odvjetnika prestaje radni odnos ako ovim Zakonom nije drukčije određeno (članak 74. i 75.).
