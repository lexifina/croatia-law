# Članak 108.
(1) Pritvor određen prema članku 102. stavku 2. točki 2. ovoga Zakona ukinut će se čim budu prikupljeni, odnosno izvedeni dokazi zbog čijeg je osiguranja pritvor određen, a najkasnije do završetka glavne rasprave.
(2) Pritvor određen prema članku 102. stavku 4. ovoga Zakona može trajati najdulje mjesec dana.
