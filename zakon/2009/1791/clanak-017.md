# Članak 17.
U članku 26. iza stavka 2. dodaje se novi stavak 3. koji glasi:
»(3) Povjerenstvo iz članka 24. stavka 2. ovoga Zakona provodi postupak za proglašavanje rješenja o registraciji oznake ništavim.«
Dosadašnji stavak 3. postaje stavak 4.
Dosadašnji stavak 4. koji postaje stavak 5. mijenja se i glasi:
»(5) Ministarstvo objavljuje u »Narodnim novinama« poništenje naziva registrirane oznake koja je rješenjem iz stavka 1. ovoga članka proglašena ništavnom.«
