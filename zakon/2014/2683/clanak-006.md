# Članak 6.
U članku 29. stavku 2. riječ: »pet« zamjenjuje se riječju: »tri«.
U stavku 4. druga i treća rečenica brišu se.
Iza stavka 4. dodaje se stavak 5. koji glasi:
»(5) Obveza plaćanja poreza na dobit i vođenja poslovnih knjiga prema propisima o računovodstvu poduzetnike iz stavka 4. ovoga članka obvezuje sljedeće tri godine. U opravdanim slučajevima i na temelju pisanog zahtjeva poreznog obveznika taj rok može biti i kraći, o čemu Porezna uprava donosi rješenje. Opravdanim slučajevima osobito se smatraju cjelovita promjena djelatnosti koju obavlja porezni obveznik te značajno izmijenjeni uvjeti (više od 50%) zbog kojih je porezni obveznik promijenio način oporezivanja.«.
