# Članak 4.
U članku 34. stavak 2. mijenja se i glasi:
»(2) Nadzor nad utvrđivanjem, evidentiranjem, naplatom i ovrhom radi naplate poreza na potrošnju obavlja nadležno tijelo za utvrđivanje poreza.«.
Iza stavka 2. dodaje se stavak 3. koji glasi:
»(3) Nadležno tijelo za utvrđivanje poreza na potrošnju propisuje se odlukom grada odnosno općine.«.
