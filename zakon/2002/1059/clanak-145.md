# Članak 145.
U članku 341. stavku 1. riječi: »na glavnoj raspravi« zamjenjuju se riječima: »do završetka dokaznog postupka«.
Iza stavka 3. dodaje se stavak 4. koji glasi:
»(4) Nakon izmjene, proširenja ili podnošenja nove optužnice, optuženik će se očitovati o njezinoj osnovanosti sukladno odredbi članka 320. stavka 4. ovoga Zakona.«
