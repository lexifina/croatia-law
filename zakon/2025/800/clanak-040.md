# Članak 40.
U članku 261. stavku 4. riječi: »u ustanovi socijalne skrbi« zamjenjuju se riječima: »kod poslodavca u djelatnosti socijalne skrbi«, a riječi: »ustanova kao poslodavac otkazat će« zamjenjuju se riječima: »poslodavac će otkazati«.
U stavku 5. riječi: »ustanova kao poslodavac« zamjenjuju se riječju: »poslodavac«, a riječi: »u ustanovi socijalne skrbi« zamjenjuju se riječima: »kod poslodavca u djelatnosti socijalne skrbi«.
