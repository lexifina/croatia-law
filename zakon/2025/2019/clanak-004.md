# Članak 4.
U članku 24. stavku 2. točki 2. iza riječi: »od dana« dodaje se riječ: »zaprimanja«.
Iza stavka 2. dodaje se novi stavak 3. koji glasi:
»(3) Ako je prijava podnesena izravno policiji i/ili državnom odvjetništvu, a ta su tijela ujedno jedina nadležna za postupanje po sadržaju prijave, ne primjenjuje se odredba stavka 2. točke 4. ovoga članka.«.
Dosadašnji stavak 3. postaje stavak 4.
