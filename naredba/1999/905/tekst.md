I.
U Naredbi o razdobljima za ponovno umjeravanje etalona i ovjernim razdobljima za ponovno ovjeravanje mjerila (»Narodne novine« br. 50/96 i 103/96) u točki II. podtočki 5. redak b) mijenja se i glasi:
»b) vage za ispitivanje utega |  | 2 godine«
Iza retka d) dodaje se novi redak e) koji glasi:
»e) etaloni mase veće od 50 kg |  |  | 5 godina.«
II.
U točki IV. podtočka 1. mijenja se i glasi:
»1. duljine:
a) elektronički taksometri |  |  |  | 2 godine
To ovjerno razdoblje ne primjenjuje se na elektro-
ničke taksometre iz članka 43. Pravilnika o
mjeriteljskim zahtjevima za taksometre (»Narodne
novine« br. 13/96 i 163/98).
b) elektronički taksometri iz članka 43. Pravilnika
o mjeriteljskim zahtjevima za taksometre i
mehanički taksometri |  |  |  |  | 1 godina
c) mjerila prijeđenoga puta (hodometri) |  | 1 godina
d) mjerila duljine prijeđenoga puta u motornim
vozilima za iznajmljivanje osobama koje same
voze |  |  |  |  |  |  | 1 godina
e) metri za tekstil |  |  |  |  | 2 godine
f) uređaji za mjerenje duljine žice i kabela |  | 1 godina
g) savitljivo mjerilo duljine s mjernom trakom |  | 2 godine.«
U podtočki 3. iza retka e) dodaje se novi redak f)
koji glasi:
»f) magnetno-induktivna mjerila obujma hladne
vode |  |  |  |  |  |  | 6 godina.«
Iza podtočke 10. dodaje se nova podtočka 11. koja glasi:
»11. vage kojima se mjeri udio aditiva koji se
dodaju namirnicama |  |  |  |  | 2 godine.«
III.
U točki VIII. podtočki 1. redak c) mijenja se i glasi:
»c) osobne vage, uključujući vage za dojenčad |  |  |  |  |  |  | 2 godine«
Iza retka h) dodaje se novi redak i) koji glasi:
»i) vage za pripravu lijekova i drugih medicinskih
pripravaka |  |  |  |  |  | 2 godine.«
IV.
U točki IX. iza podtočke 10. dodaju se nove podtočke 11. i 12. koje glase:
»11. vage kojima se mjeri udio štetnih tvari u
vodoopskrbnim sustavima vode za piće |  |  | 2 godine
12. vage kojima se mjeri udio štetnih tvari u
otpadnim vodama i drugom industrijskom
otpadu |  |  |  |  |  | 2 godine.«
V.
U točki XIII. iza riječi »ugradbe« dodaju se riječi: »i taksometre za koje ovjerno razdoblje teče od prvoga dana sljedećeg mjeseca od mjeseca u kojem je obavljeno ovjeravanje.«
VI.
Ova naredba stupa na snagu osmoga dana od dana objave u »Narodnim novinama«.
