# Članak 14.

- ako je izgrađena bez akta, odnosno
protivno aktu kojim se odobrava građenje KK1 = 1,2
- ako je protivna planu koji se primjenjuje KK2 = 1,1
- ako nije za vlastite potrebe KK3 = 1,05.
