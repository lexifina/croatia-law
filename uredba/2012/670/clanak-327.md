# Članak 327.
Odsjek provedbe programa izvršavanja kazne zatvora obavlja poslove provedbe pojedinačnih programa izvršavanja kazne zatvora i sigurnosnih mjera, procjenjivanja uspješnosti pojedinog zatvorenika u provedbi pojedinačnog programa izvršavanja kazne zatvora, predlaganja izmjena pojedinačnog programa izvršavanja kazne zatvora, provođenja posebnih programa postupanja, obrazovanja zatvorenika i organizacije slobodnog vremena, izrade stručnih mišljenja o tijeku izvršavanja kazne zatvora, vođenja stručnog tima za izvršavanje kazne zatvora.
