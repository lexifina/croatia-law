# Croatian law in charts

[Hrvatski](README.md)

Charts on every country's law, from the whole of global-law: [global-law visualisations/](https://github.com/lexifina/global-law/tree/main/visualisations). This folder will hold the charts on Croatia alone.

**This is a placeholder.** The charts on Croatian law have not been drawn yet. When they are, they will be drawn only from the data in this repository, like the [charts on Serbian law](https://github.com/lexifina/serbia-law/tree/main/visualisations): one HTML page with all its data inside, each chart with the data's path in the repository, its record count and its limits, and a table of every number below it.

## Data

The charts will read these parts of the repository:

| Dataset | Where it is in the repository |
| --- | --- |
| Git history | branch `main` (the commit date is the day of entry into force or of decision) |
| Acts of the official part of Narodne novine | `<kind>/<year>/<number>/`, `registry/data/acts.json` |
| Constitution | `ustav/` |
| Case law | `caselaw/ustavni-sud/`, `caselaw/vrhovni-sud/`, `caselaw/visoki-upravni-sud/` |
| International treaties | `medunarodni/` |
| Local acts | `local/` |
