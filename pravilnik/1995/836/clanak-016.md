# Članak 16.
Referentna temperatura je temperatura okoline od 23 C + 3 C pri kojoj se uklopni sat ispituje. Radno područje je od
-10 C do +45 C; granično područje radaje od -20 C 2 C do + 55 C + 2 C; granično područje za skladištenje i prijevoz je od -25 C do + 70 C. Skladištenje i prijevoz uz krajnje temperature ograničeno je na razdoblje od najviše 6 sati. Ako su te temperature neprihvatljive za baterije, prihvatljiva će se temperatura jasno označiti na uklopnom satu.
