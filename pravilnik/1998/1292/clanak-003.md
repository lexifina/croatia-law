## 2. NAČIN ODREĐIVANJA NAKNADE
# Članak 3.
Naknada koju plaćaju obveznici iz članka 2. točaka 1., 2., 3. i 4. ovog Pravilnika određuje se prema izrazu:
N = N0 x V1 x k1
u kojem su:
N = ukupni iznos naknade,
N0 = visina naknade - tarifa (prema propisu iz članka 12. stavka 1. Zakona o financiranju vodnog gospodarstva - u daljnjem tekstu - prema Odluci),
V1 = količina korištene vode u mł za obračunsko razdoblje,
k1 = korekcijski koeficijent za vrstu vode (prema - Odluci).
Naknada koju plaćaju obveznici iz članka 2. točke 5. ovog Pravilnika određuje se prema izrazu:
N = N0 x V2 x k1 x 0,05
u kojem su:
N = ukupni iznos naknade,
V2 = količina korištene vode izražena kroz obujam bazena ribogojilišta u m3
N0 = visina naknade - tarifa,
k1 = korekcijski koeficijent za vrstu vode.
Naknada koju plaćaju obveznici iz članka 2. točke 6. ovog Pravilnika određuje se prema izrazu:
N = N1 x V3 x k2
u kojem je:
N = ukupni iznos naknade,
N1 = visina naknade - tarifa (prema propisu iz članka 12. stavka 2. Zakona o financiranju vodnog gospodarstva, u daljnjem tekstu Odluka županijske skupštine),
V3 = ukupna količina korištene vode u mł u obračunskom razdoblju,
k2 = korekcijski koeficijent izgrađenosti koji određuje županijska skupština na prijedlog "Hrvatskih voda".
Obveznici koji koriste vodu za navodnjavanje u melioracijskom sustavu za koje nije moguće pojedinačno mjerenje količina korištene vode, plaćaju povećani iznos slivne vodne naknade na temelju rješenja "Hrvatskih voda".
Povećani iznos slivne vodne naknade iz stavka 4. ovog članka određuje županijska skupština pripadajućeg slivnog područja na prijedlog "Hrvatskih voda".
Naknada koju plaćaju obveznici iz članka 2. točke 7. ovog Pravilnika određuje se prema izrazu:
N = N2 x E
u kojem je:
N = ukupni iznos naknade,
E = količina proizvedene električne energije u kWh u obračunskom razdoblju na pragu svih hidroelektrana obveznika,
N2 = visina naknade za jedan kWh prema Odluci.
Naknada koju plaćaju obveznici iz članka 2. točke 8. ovog Pravilnika određuje se prema izrazu:
N = N3 x S
u kojem je:
N = ukupni iznos naknade,
N3 = visina naknade za 1 kW - tarifa (prema Odluci),
S = ukupna snaga postrojenja u kW.
