# Članak 6.
Područna selekcijska služba dužna je za rad Povjerenstva pripremiti uzgojne i reprodukcijske podatke o uzgojno valjanim rasplodnjacima koji se licenciraju odnosno ocjenjuju. Pripremljeni podaci dostavljaju se županijskom uredu odnosno uredu Grada Zagreba nadležnom za poslove stočarstva (u daljnjem tekstu: županijski ured) prije početka licenciranja odnosno ocjene grla.
