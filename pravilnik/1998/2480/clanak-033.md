# Članak 33.
Polazniku se na završetku svakog razreda izdaje razredna svjedodžba.
Polazniku koji položi maturu odnosno završni ispit izdaje se maturalna svjedodžba odnosno svjedodžba o završnom ispitu.
Polazniku koji uspješno završi program osposobljavanja odnosno program usavršavanja izdaje se potvrda o osposobljenosti odnosno potvrda o usavršavanju.
Svjedodžbe iz stavka 1. i 2. i potvrde iz stavka 3. ovoga članka izdaje škola ili druga pravna osoba.
