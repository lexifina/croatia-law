# Članak 2.
U članku 4. iza stavka 2. dodaje se novi stavak 3. koji glasi:
»Nakon zaprimanja ovjerene tiskanice iz stavke 2. ovog članka, poslodavac je obvezan o promjeni obavijestiti dosadašnjeg doktora SMR koji je u roku od 8 dana od primitka te obavijesti obvezan novo odabranom doktoru SMR predati svu zdravstvenu dokumentaciju o osiguranim osobama za koje je obavljena promjena doktora SMR, te sukladno propisima o vođenju i čuvanju medicinske dokumentacije pohraniti potpisanu izjavu o preuzetoj medicinskoj dokumentaciji.«
Dosadašnji stavci 3. i 4. postaju stavci 4. i 5.
