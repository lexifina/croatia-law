## OBRAZOVNI PROGRAM
# Članak 2.
(1) Obrazovni program za obavljanje poslova investicijskog savjetnika organizira Komisija za vrijednosne papire, a odluku o tome objavljuje u javnim glasilima.
(2) Obrazovni program bit će organiziran ako se za isti prijavi najmanje 20 polaznika.
(3) Pohađanje obrazovnog programa nije uvjet za pristupanje ispitu za obavljanje poslova investicijskog savjetnika.
(4) Obrazovni program može pohađati osoba koja je stekla najmanje VI/1 (šesti) stupanj obrazovanja.
(5) Troškove obrazovnog programa snose polaznici, plaćanjem kotizacije prije početka pohađanja programa.
