# Članak 3.
Sredstva naknade koriste se za programe i mjere osposobljavanja neplodnog zemljišta i povećanja proizvodne sposobnosti ostalog poljoprivrednog zemljišta (u daljnjem tekstu: program uređenja zemljišta).
Program uređenja zemljišta podrazumijeva:
1. Agromelioracije
• humizacija tla
• kalcifikacija tla
• meliorativna gnojidba
2. Hidromelioracije
• odvodnja (osnovna odvodnja, kanalska mreža, detaljna odvodnja - drenaža)
• navodnjavanje (sustavi za navodnjavanje, vodozahvati - iskop bunara)
3. Okrupnjavanje posjeda kupovinom poljoprivrednog zemljišta.
