# Članak 40.
Park prirode kao područje s naglašenim estetskim, turističkim i rekreativnim vrijednostima namijenjen je i posjećivanju.
Ustanova donosi program (model) posjećivanja i razgledavanja kojim se pobliže uređuju moguća mjesta posjećivanja, istovremeni broj posjetitelja, način posjećivanja i organiziranja prezentacijskog centra Ustanove.
