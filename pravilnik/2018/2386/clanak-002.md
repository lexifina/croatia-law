# Članak 2.
U članku 2. stavku 1. riječ: »sudskim« zamjenjuje se riječju: »prekršajnim« te se riječi: »na prekršajnim« zamjenjuju riječima: »u općinskim«.
U stavku 2. u točki 2. iza riječi: »evidencijom« briše se točka te dodaju zarez i točke 3. i 4. koje glase:
»3. sustavom Ministarstva unutarnjih poslova,
4. sustavom Državnog zavoda za statistiku.«.
