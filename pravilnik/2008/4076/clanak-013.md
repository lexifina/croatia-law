## Nacionalni program kontrole
# Članak 13.
Nacionalni program kontrole ostataka pesticida
(1) Nadležna uprava uspostavlja višegodišnji nacionalni program kontrole ostataka pesticida. Program se ažurira svake godine.
Program je temeljen na procjeni rizika i usmjeren posebice na procjenu izloženosti potrošača i sukladnosti sa važećim zakonodavstvom. Program sadrži najmanje sljedeće:
a) proizvode koji se uzorkuju;
b) broj uzoraka koji se uzimaju i analiza koje se trebaju provesti;
c) pesticide koji se analiziraju;
d) kriterije koji se primjenjuju u izradi takvih programa, uključujući:
i. izabranu kombinaciju pesticid/proizvod;
ii. broj uzoraka uzetih podjednako od domaćih i inozemnih proizvoda;
iii. zastupljenost proizvoda u nacionalnoj prehrani;
iv. program kontrole Zajednice; i
v. rezultate prethodnih programa kontrole.
(2) Rezultati nacionalnog programa praćenja ostataka pesticida objavljuju se na web-stranicama Ministarstva poljoprivrede, ribarstva i ruralnog razvoja svake godine. U slučaju prekoračenja MDK, Ministarstvo poljoprivrede, ribarstva i ruralnog razvoja kao nadležno tijelo (dalje u tekstu nadležno tijelo) može objaviti ime trgovca na malo, distributera ili proizvođača.
