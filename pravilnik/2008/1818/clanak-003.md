# Članak 3.
U članku 5. iza stavka 3. dodaje se novi stavak 4. koji glasi:
»U potrošačkim sporovima troškovi mirenja izvan sjedišta Centra, odnosno sjedišta ureda Centra podmiruju se iz sredstava državnog proračuna u smislu odredbe članka 130., stavka 4. i stavka 6. Zakona o zaštiti potrošača (»Narodne novine« br. 79/07.).«
