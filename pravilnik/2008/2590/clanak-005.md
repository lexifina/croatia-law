# Članak 5.
Radnje i postupci koje primjenjuje psiholog jesu:
1. intervju s oba bračna druga, odnosno osobom koja je podnijela zahtjev,
2. intervju sa svakim bračnim drugom pojedinačno,
3. testiranje oba bračna druga putem ispunjavanja upitnika MMPI-2-Minnesota multifazični inventar ličnosti ili dva od sljedećih upitnika:
- NEO-PI-R Revidirani NEO inventar ličnosti,
- Cornell indeks,
- PIE Indeks profila emocija
- ispunjavanje testa sposobnosti (SPM Standardne progresivne matrice ili TOS Test općih sposobnosti
- upitnici i skale za ispitivanje stavova (Upitnik bračne usklađenosti; Skala interpersonalne orijentacije-IO; ili Skala motivacije za roditeljstvo)
- primjena projektivne tehnike (Mozaik test ili Wartegg test crteža)
4. razgovor s bračnim drugovima, odnosno osobom koja je podnijela zahtjev nakon obrade, i upoznavanje s rezultatima obrade.
