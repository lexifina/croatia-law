# Članak 2.
U članku 15. stavku 3. podstavak 3. briše se.
Dosadašnji podstavci 4. - 6. postaju podstavci 3. - 5.
U dosadašnjem postavku 5. koji postaje podstavak 4. riječi: »puni tri godine u činu« zamjenjuju se riječima: »puni dvije godine u činu«.
U dosadašnjem postavku 6. koji postaje podstavak 5. riječi: »završena Intergranska zapovjedno-stožerna izobrazba« zamjenjuju se riječima: »završena treća razina slijedno-rastuće časničke izobrazbe«.
