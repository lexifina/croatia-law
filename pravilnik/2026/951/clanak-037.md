# Članak 37.
(1) Odluke iz članka 4. stavka 2. podstavaka 1., 2. i 4. ovoga Pravilnika korisniku odnosno podnositelju zahtjeva dostavljaju se u skladu s člankom 15. stavkom 2. Zakona o poljoprivredi putem AGRONET-a.
(2) Odluke iz članka 4. stavka 2. podstavaka 3. i 5. ovoga Pravilnika korisniku odnosno podnositelju Zahtjeva dostavljaju se preporučenom poštom s povratnicom.
