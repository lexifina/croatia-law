# Članak 5.
U članku 31. iza stavka 2. dodaje se stavak 3. koji glasi:
»(3) Iznimno od stavka 2. ovoga članka, maksimalan broj polaznika pojedinačnoga stručnog usavršavanja koje se organizira u okviru konferencije koja uključuje temu iz područja javne nabave, je 100, pri čemu se takav program usavršavanja ne može provoditi on-line.«.
Dosadašnji stavci 3. 4. i 5. postaju stavci 4., 5. i 6.
