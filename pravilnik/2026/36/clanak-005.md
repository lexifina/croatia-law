# Članak 5.
U članku 8. stavak 2. mijenja se i glasi:
»(2) Obrasci za dostavu podataka iz članaka 4., 5. i 6. ovoga Pravilnika (upitnici) popunjavaju se putem web sučelja dostupnog na internetskoj stranici Hanfe. Nakon unosa podataka putem web sučelja, generira se XML datoteka prema tehničkoj shemi. Upute za korištenje web sučelja dostupne su na internetskoj stranici Hanfe.«.
