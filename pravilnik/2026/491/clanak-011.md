# Članak 11.
U članku 18. stavku 1. podstavku 4. riječi: »odslužen vojni rok ili uspješno završen program dragovoljnog vojnog osposobljavanja« zamjenjuju se riječima: »odslužen vojni rok ili uspješno završen program dragovoljnog vojnog osposobljavanja/uspješno završen program temeljnog vojnog osposobljavanja/uspješno završen program obuke za kadete«.
