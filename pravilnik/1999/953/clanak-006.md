# Članak 6.
Matični nasad iz kojeg se dobiva reprodukcijski materijal kategorije "certificirani sadni materijal" neće se odabrati ako broj praznih mjesta zbog fitosanitarnih razloga prelazi 5%.
Drugi razlozi većeg postotka praznih mjesta trebaju biti opravdani priloženom dokumentacijom o obavljenom stručnom nadzoru nad proizvodnjom.
