# Članak 4.
Trsovi u vinogradima odabiru se za matične ako su:
1. stariji od četiri godine;
2. dobre vegetativne razvijenosti;
3. zdravi nemaju vizualnih simptoma zaraze virusima i virusima sličnim bolestima;
4. autentične sorte.
Postupak odabira trsova traje dvije godine postupkom masovne pozitivne selekcije.
