# Članak 3.
U članku 5. stavku 1. točka 4. mijenja se i glasi:
"4. za sipu (Sepia officinalis) i lignju (Loligo vulgaris) je dužina leđnog dijela trupa izmjerena od vrha prednjeg leđnog dijela trupa do kraja leđnog dijela trupa."
Iza točke 4. dodaje se nova točka koja glasi:
"5. za hobotnicu (Octopus vulgaris) je njezina težina izmjerena u kilogramima."
