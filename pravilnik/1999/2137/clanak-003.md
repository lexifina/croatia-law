# Članak 3.
Nakon primitka pisanog zahtjeva iz članka 2. ovog Pravilnika, tijelo državne uprave nadležno za poslove rudarstva osniva Stručno povjerenstvo, koje će obaviti provjeru rudarskog projekta.
Rješenje o osnivanju Stručnog povjerenstva bit će dostavljeno rudarskom trgovačkom društvu i rudarskom obrtniku, koje je zatražilo provjeru rudarskog projekta.
