# Članak 2.
U članku 4. stavak 4. mijenja se i glasi:
»(4) Obrazac povlastice ispunjava se elektronskim putem kroz informacijski sustav ribarstva - bazu podataka pod nazivom: »Akvakultura« (u daljnjem tekstu: baza podataka »Akvakultura«), te ispisuje računalnim ispisom.«.
U članku 4. stavku 5. ispred riječi: »obrazac« dodaje se riječ: »ispunjen«.
