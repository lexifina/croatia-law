# Članak 1.
U Pravilniku o obračunu i plaćanju naknade za korištenje voda (»Narodne novine«, broj 94/98 i 108/98) u članku 3. mijenjaju se stavci 1. i 2. i glase:
»Naknada koju plaćaju obveznici iz članka 2. točka 1., 2., 3. i 4. Pravilnika određuje se prema izrazu:
N = N0 x V1
u kojem su:
N = ukupni iznos naknade
N0 = visina naknade za korištenje voda prema vrsti vode (Odluka o visini naknade za korištenje voda »Narodne novine«, broj 62/00)
V1 = količina korištene vode u m3 za obračunsko razdoblje.
Naknada koju plaćaju obveznici iz članka 2. točke 5. Pravilnika određuje se prema izrazu:
N = N0 x V2 x kr
u kojem su:
N = ukupni iznos naknade
N0 = visina naknade za korištenje voda prema vrsti vode (prema Odluci)
V2 = količina korištene vode izražena kroz obujam bazena ribogojilišta u m3
kr = korekcijski koeficijent godišnjeg povećanja ukupnog iznosa naknade (Pravilnik o izmjeni Pravilnika o obračunu i plaćanju naknade za korištenje voda »Narodne novine«, broj 48/00).«
