# Članak 1.
U Pravilniku o obračunu i plaćanju naknade za korištenje voda (»Narodne novine« broj 94/98 i 108/98) u članku 3. stavak 2. mijenja se i glasi:
»Naknada koju plaćaju obveznici iz članka 2. točke 5. ovog Pravilnika određuje se prema izrazu:
N = N0 x V2 x k1 x kr
u kojem su:
N = ukupni iznos naknade
N0 = visina naknade - tarifa
V2 = količina korištene vode izražena kroz obujam bazena ribogojilišta u m3
k1 = korekcijski koeficijent za vrstu vode
kr = korekcijski koeficijent godišnjeg povećanja ukupnog iznosa naknade, koji iznosi za
- 2000. i 2001. godinu | 0,01
- 2002. godinu |  | 0,02
- 2003. godinu |  | 0,03
- 2004. godinu |  | 0,04
- 2005. i daljnje godine | 0,05.«
