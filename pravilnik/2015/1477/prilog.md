2. Adresa (ulica, kućni broj, broj pošte, mjesto)
3. Matični broj
4. Osobni identifikacijski broj
KONCESIONAR
1. Naziv ili ime
2. Adresa (ulica, kućni broj, broj pošte, mjesto)
3. Matični broj, matični broj građana ili broj osobne iskaznice

PODACI O KONCESIJI
1. Naziv koncesije iz ugovora
2. Lokacija koncesije (grad/općina ili više njih)
3. Datum zaključenja ugovora (dan, mjesec, godina)
4. Datum početka ostvarivanja koncesije (dan, mjesec, godina)
5. Datum isteka koncesije (dan, mjesec, godina)
KONTAKT PODACI
1. Osoba za kontaktiranje
2. Telefon
3. Telefaks
4. Adresa e-pošte
