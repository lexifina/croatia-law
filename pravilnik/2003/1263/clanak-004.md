# Članak 4.
Ustanova je dužna skrbiti o zaštiti, očuvanju, održavanju, korištenju, unaprjeđenju i promicanju Parka prirode.
Ustanova upravlja područjem Parka prirode na temelju programa zaštite, održavanja, očuvanja, promicanja i korištenja Parka prirode (u daljnjem tekstu: Program zaštite i očuvanja) i plana upravljanja sukladno Zakonu o zaštiti prirode i ovom Pravilniku.
