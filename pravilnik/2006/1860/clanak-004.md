# Članak 4.
Članak 4. mijenja se i glasi:
»(1) Pravna ili fizička osoba obvezna je prethodno ishoditi odobrenje za provođenje psihosocijalnog tretmana izvan zdravstvene ustanove (u daljnjem tekstu: odobrenje).
(2) Odobrenje iz stavka 1. ovoga članka rješenjem daje ministar nadležan za poslove pravosuđa.«
