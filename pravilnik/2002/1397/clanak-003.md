# Članak 3.
Izrazi u ovom pravilniku znače:
1. metoda mjerenja snage i vremena je posredna mjerna metoda pomoću koje se dobiva električna energija mjerenjem snage i vremena;
2. metoda mjerenja rada - usporedbe s etalonskim brojilom je izravna usporedbena mjerna metoda kod koje se mjereni električni rad uspoređuje s poznatom vrijednosti iste veličine koju reproducira utjelovljena mjera koja se izravno upotrebljava pri mjerenju.
