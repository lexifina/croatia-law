# Članak 2.
Pod plinomjerima se, prema ovom Pravilniku razumijevaju:
1. plinomjeri s tekućinom
2. plinomjeri s mjehovima odnosno pokretnim stijenkama promjenjivog oblika
2.1. plinomjeri s mjehovima odnosno pokretnim stijenkama promjenjivog oblika i pretplatničkim uređajem
2.2. plinomjeri s mjehovima odnosno pokretnim stijenkama promjenjivog oblika i temperaturnom korekcijom
3. plinomjeri s rotacijskim klipovima
4. plinomjeri s turbinom.
