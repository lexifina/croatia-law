# Članak 13.
Kao mjerilo protekloga vremenskog razmaka upotrebljava se mjerilo vremena, mjernog opsega od 0 s do 3 600 s, kojemu je vrijednost najmanjeg podjeljka 1/10 s.
Mjerilo protekloga vremenskog razmaka može imati osjetila (senzorske elemente) za automatsko upravljanje procesom mjerenja trajanja vremenskog razmaka.
