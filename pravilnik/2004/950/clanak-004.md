# Članak 4.
U članku 15. iza stavka 2. dodaje se novi stavak 3. koji glasi:
»(3) Stručni radnik koji nije u radnom odnosu a ima u odgovarajućoj struci radni staž dulji od vremena određenog za vježbenički staž može, ako to želi, polagati stručni ispit.«
U dosadašnjem stavku 3. koji postaje stavak 4. brojevi: »1. i 2.« zamjenjuju se brojevima: »1., 2. i 3.«.
