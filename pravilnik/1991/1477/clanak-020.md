# Članak 20.
Registarska pločica zamijenit će se novom registarskom pločicom:
1. ako se vozilo registrira u drugom registarskom području:
2. ako se izgubi ili bude uništena;
3. ako zbog dotrajalosti postane neupotrebljiva.
Umjesto registarske pločice koja je nestala ne može se izdati nova registarska pločica s istim registarskim brojem prije nego što proteknu dvije godine od dana kad je prijavljen nestanak registarskih pločica.
