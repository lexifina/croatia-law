# Članak 3.
Posrednici iz članka 4. stavka 2. i 3. Zakona o zapošljavanju mogu obavljati poslove posredovanja pri zapošljavanju pod uvjetom da:
- imaju hrvatsko državljanstvo,
- ispunjavaju uvjete iz članka 4. ovoga Pravilnika,
- poslove posredovanja pri zapošljavanju obavljaju kao registriranu djelatnost.
