# Članak 21.
Isklična cijena u 1. krugu jednaka je ukupnoj nazivnoj vrijednosti ponuđenih dionica društva (vrijednost iz elaborata o pretvorbi ili tržišna vrijednost ako se dionicama društva trguje javno na uređenim tržištima i to tako da:
VT = nazivna ili preinačena vrijednost ponuđenih dionica društva
S I = Prvotni broj ponuđenih dionica po dioničkom društvu
P I = Prvotna cijena po dionici ( VT/SI )
Ukupan broj bodova koji se nadmeće na dražbi, izračunava se za svako društvo:
Bodovi u posjedu ovlaštenog sudionika = q
Ukupni bodovi ponuđeni za dionice društva B= Sq
Stopa potražnje na dražbi = R A = B/VT
U 1. i 2. krugu nadmetanja za dionice nekog dioničkog društva dražba se smatra uspješnom ako je stopa potražnje unutar unaprijed utvrđenog raspona, ako je:
1-0,33 < =RA< =1+0,33
Dražba se smatra neuspješnom ako uvjet iz prethodnog stavka nije zadovoljen i ako je:
1-0,33 > =RA> =1+0,33
Ako je dražba neuspješna, dionice se prebacuju u drugi krug po preinačenoj cijeni.
U 3. krugu je dražba uspješna neovisno o stopi potražnje.
