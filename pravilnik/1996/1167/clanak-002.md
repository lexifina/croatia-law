# Članak 2.
U članku 18. iza stavka 2. dodaje se stavak 3. koji glasi:
"Pored uvjeta iz stavka 2. ovoga članka, ovlaštene službene osobe koje upravljaju vozilima iz članka 6. stavka 2. ovoga Pravilnika, moraju biti osposobljene za korištenje ugrađenih uređaja za utvrđivanje prekršaja u pokretu".
Dosadašnji stavci 3. i 4. postaju stavci 4. i 5.
Iza stavka 5. dodaje se stavak 6. koji glasi:
"Iznimno od stavka 4. ovoga članka, ovlaštene službene osobe mogu upravljati vozilima iz članka 6. stavka 2. ovoga Pravilnika i u građanskoj odjeći".
