# Članak 53.
(1) Stupanjem na snagu ovoga Pravilnika prestaje važiti Pravilnik o provedbi Mjere 103 unutar IPARD programa (»Narodne novine« broj 24/2013).
(2) Postupci obrade prijava koje je Agencija za plaćanja počela obrađivati sukladno odredbama Pravilnika o provedbi Mjere 103 unutar IPARD programa (»Narodne novine« broj 24/2013) dovršiti će se po odredbama toga Pravilnika.
