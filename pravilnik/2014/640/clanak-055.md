# Članak 55.
(1) Stupanjem na snagu ovoga Pravilnika prestaje važiti Pravilnik o provedbi Mjere 101 unutar IPARD programa (»Narodne novine« broj 24/2013).
(2) Postupci obrade prijava koje je Agencija počela obrađivati sukladno odredbama Pravilnika o provedbi Mjere 101 unutar IPARD programa (»Narodne novine« broj 24/2013) dovršit će se po odredbama toga Pravilnika.
