# Članak 21.
(1) Ovlašteni carinski službenik po završetku uzorkovanja uzorak, zapisnik o uzorkovanju, pripadajuće isprave i dokumentaciju dostavlja ustrojstvenoj jedinici Ministarstva financija Carinske uprave, koja je nadležna za čuvanje uzoraka (u daljnjem tekstu: ustrojstvena jedinica čuvanja uzorka).
(2) Ustrojstvena jedinica čuvanja uzorka u pravilu je područni carinski ured nadležan prema mjestu uzorkovanja, neovisno o ustrojstvenoj jedinici uzorkovanja.
