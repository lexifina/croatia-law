# Članak 4.
Izvješća iz članka 2. ovog Pravilnika pohranjuju se u Ministarstvo pravosuđa za vrijeme trajanja obnašanja sudačke odnosno državnoodvjetničke dužnosti.
Prestankom obnašanja sudačke odnosno državnoodvjetničke dužnosti, izvješća iz članka 2. ovog Pravilnika pohranjuju se u pismohrani Ministarstva pravosuđa.
