# Članak 2.
U članku 3. stavku 1. točki 4. brojka: »15.000« zamjenjuje se brojkom: »25.000«.
U stavku 3. riječi: »točki 4.« zamjenjuju se riječima: »točki 2. i 4.«, a na kraju stavka dodaje se nova rečenica koja glasi:
»Obavijest o potrebi povećanja kapaciteta odnosno dogradnji nove tehnološke linije vlasniku postojeće stanice za tehnički pregled dostavlja stručna organizacija.«.
