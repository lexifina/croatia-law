# Članak 8.
Ukupni operativni troškovi izračunavaju se prema sljedećoj formuli:
UOT = LCkm x ((potrošnjaE x PE x CEmin/PEmin) + (CO2em x CCO2) + (NOxem x CNOx) + NMHCem x CNMHC) + PMem x CPM))
gdje je:
UOC = ukupni operativni troškovi
LCkm = prijeđeni kilometri u radnom vijeku vozila
potrošnjaE = potrošnja energenata
PE = ogrjevna vrijednost energenta
PEmin = ogrjevna vrijednost najjeftinijeg energenta
CEmin = cijena najjeftinijeg energenta
CO2em = emisije ugljikovog dioksida
CCO2= cijena za emisije ugljikovog dioksida
NO2em = emisije dušikovih oksida
CNox= cijena za emisije dušikovih oksida
NMHCem = emisije nemetanskih ugljikovodika
CNMHC= cijena za emisije nemetanskih ugljikovodika
PMem = emisije čestica
CPM = cijena za emisije čestica
Podaci koje u svojoj ponudi mora navesti ponuđač, osim nabavne cijene vozila, su:
- potrošnja energenata izražena u l/km ili kWh/km,
- emisija ugljikovog dioksida (CO2em) izražena u kg/km,
- emisija ugljikovog dušikovih oksida (NOxem) izražena u g/km,
- emisija nemetanskih ugljikovodika (NMHCem ) izražena u g/km,
- emisija čestica (PMem) izražena u g/km,
Vrijednosti koje određuje sam naručitelj su:
LCkm = kilometri u radnom vijeku vozila
PE = ogrjevna vrijednost energenta
PEmin = ogrjevna vrijednost najjeftinijeg energenta
CEmin = cijena najjeftinijeg energenta
CCO2= cijena za emisije ugljikovog dioksida
CNox= cijena za emisije dušikovih oksida
CNMHC= cijena za emisije nemetanskih ugljikovodika
CPM = cijena za emisije čestica
Pri izračunu ukupnih operativnih troškova u životnom vijeku vozila moraju se upotrijebiti vrijednosti koje je u svojoj ponudi naveo ponuđač kao i vrijednosti koje je sam odredio naručitelj.
